# CSharp WinForms Project

## Overview
This project is a Windows Forms application developed using C# and Visual Studio.

## Technologies
- C#
- Windows Forms
- .NET Framework 4.7.2
- Visual Studio

## Project Structure
- `Program.cs`: Application entry point.
- `Form1.cs`: Main form.
- `Form2.cs`: Additional form.
- `Form3.cs`: Additional form.
- `.sln`: Visual Studio solution file.
- `.csproj`: C# project file.

## How to Run
1. Download or clone this repository.
2. Open the `.sln` file with Visual Studio.
3. Restore any required dependencies.
4. Build and run the project.

## Notes
This project was developed for learning and practice purposes.
